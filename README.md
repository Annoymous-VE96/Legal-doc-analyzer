# LexAI

AI-powered legal document analyzer. Upload PDFs and chat with them using RAG (retrieval-augmented generation) + web search fallback.

## Tech Stack
- FastAPI backend
- React frontend
- LangChain + LangGraph (CRAG pipeline)
- FAISS vector store
- Postgres (Neon)
